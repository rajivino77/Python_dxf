# Python_dxf
Python program to read the real time serial data from external devices.
Integrated PS5 DualSense and standard game controllers using the inputs library for cross-platform support.
Mapped joystick movements to control x, y coordinates and button presses to trigger drawing of lines, circles, and holes.
Visualized geometric shapes (lines, circles, holes) dynamically using Matplotlib. 
Generated CAD-compatible `.dxf` files from plotted data using ezdxf. 
Implemented email automation to send generated DXF files using smtplib.
